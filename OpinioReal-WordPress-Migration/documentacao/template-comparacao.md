# Template de comparação

## Estrutura

1. Breadcrumb
2. H1 + introdução
3. Bloco de escolha rápida
4. Tabela comparativa
5. Cards/destaques por perfil
6. Análises individuais
7. Prós e contras
8. Critérios de decisão
9. FAQ
10. Conclusão
11. CTA e links relacionados

## Destaques

Usar etiquetas editoriais somente quando sustentadas pela análise:

- **Melhor escolha**
- **Melhor custo-benefício**
- **Melhor alternativa**
- **Melhor para iniciantes**

Não usar estrelas, notas ou selos sem metodologia e dados verificáveis.

## Tabela

Colunas devem representar critérios que realmente diferenciam as opções. No mobile, manter a tabela em `overflow-x: auto` para não sacrificar leitura.

## Elementor

- Container principal de conteúdo.
- Widget/loop para cards quando o conteúdo for dinâmico.
- Tabela HTML/TablePress quando apropriado.
- CTA com URL rastreável/Pretty Links quando instalado.

O visual deve continuar editorial e não assumir aparência de marketplace.
