# Template de artigo SEO

## Composição visual

**Topo:** breadcrumb discreto, categoria/tipo editorial, H1 Playfair, autoria e datas.

**Imagem:** destaque em largura controlada, nítida e com ALT editorial.

**Introdução:** parágrafos confortáveis, largura de leitura estreita.

**Resumo rápido:** superfície suave com síntese da decisão.

**Conteúdo:** H2/H3, parágrafos, listas, citações/fontes quando existirem.

**Tabela:** comparação em container com rolagem horizontal no mobile.

**Análise:** blocos de produto com imagem, indicação, resumo, prós/contras e CTA. Sem dados inventados.

**Uso diário:** explicar adequação ao contexto sem afirmar teste físico inexistente.

**FAQ:** acordeão visível; perguntas e respostas alimentam o mesmo conteúdo usado no FAQ schema.

**Conclusão:** síntese equilibrada, sem urgência artificial.

**CTA:** `Ver preço atualizado`, `Confira a oferta` ou `Veja a análise completa`, usando URL afiliada real e `rel="sponsored noopener noreferrer"`.

**Relacionados:** links para a página-pilar, subcategoria, comparativo e guias relevantes.

## Campos WordPress

- Título
- Slug
- Conteúdo
- Tipo: review/guide/comparison
- Categoria/tópico
- Meta title
- Meta description
- Palavra-chave principal
- Secundárias
- Canonical
- Imagem destacada + ALT
- Fontes
- FAQ
- Relacionados
- Disclosure de afiliado
- Data de publicação
- Data de atualização

## Rank Math

Manter title e description editoriais, sem keyword stuffing. Canonical deve preservar URL final. Breadcrumbs e Article schema devem apontar para a página atual. FAQ schema só quando o FAQ estiver realmente visível.

## Elementor

Reproduzir como Theme Builder/Single Post Template, usando containers para blocos e widgets apenas onde isso não altere a semântica. O conteúdo deve continuar editável no WordPress, não ficar embutido no template.
