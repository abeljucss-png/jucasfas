# Assets

Use esta pasta como índice de recursos de migração. Os originais continuam no projeto atual.

- `brand/`: logo e marca.
- `icons/`: ícones recorrentes, preferencialmente SVG.
- `fonts/`: somente se a estratégia de hospedagem local for escolhida.
- `video/`: thumbnails e referências de vídeo.
- `seo/`: assets editoriais específicos.

A regra é referenciar os arquivos originais e só duplicar quando o pacote final for entregue a um ambiente WordPress independente.
